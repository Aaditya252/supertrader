# Phase 2 architecture and mathematical contract

Written before implementation, 2026-10-08. This extends the existing signals-only terminal. Research support for perpetual simulation does not enable real-money futures execution.

## Data and time contract

Official Binance spot and USD-M SOLUSDT aggregated-trade archives, September 2020 through the recorded snapshot cutoff, are stored in monthly raw Parquet partitions. Aggregated trades are not individual fills: raw trade counts are reconstructed from inclusive first/last trade IDs where supplied. Maker-buy means a taker sell. Tick-derived bars share one implementation with live incremental builders: open/close follow timestamp and aggregate-ID ordering, high/low are extrema, volume is sum(q), VWAP=sum(p*q)/sum(q), taker buy/sell are classified by maker side, CVD is sum(buy-sell). Intervals: 30s, 1m, 5m, 15m, 1h, 2h, 4h, 6h, 12h, 1d.

Availability is bar end plus one millisecond for historical bars, an explicit exchange-time latency assumption. Live bars additionally wait for observed events and a configurable watermark; late events are quarantined, never retroactively treated as known predictions. Empty tick buckets remain absent. Exchange outages and no-trade buckets cannot always be distinguished without independent status logs. No interpolation invents trades. Current missing archive days are REST-backfilled within a frozen cutoff with retries and exchange rate limits.

Archive SHA-256 receipts, Parquet hashes, ID/time checks, duplicate counts, price/volume bounds, anomalous jump flags and coverage reports accompany each partition. Outliers are flagged rather than removed merely for large price moves. A DuckDB catalog exposes Parquet views without loading the complete history. The universe is SOL plus BTC/ETH context and cannot establish cross-coin survivorship robustness.

Funding history is obtainable in monthly futures fundingRate archives. Historical OI and position ratios use daily futures metrics where available, with coverage discovered rather than assumed back to 2020. Mark/index premiums use native historical klines where available. Historical bookDepth files represent depth aggregates, not sequenced L2 snapshots; they cannot reconstruct historical microprice/OFI. Existing native live sequenced books supply these only prospectively. Tardis/Coinglass/CryptoQuant require separate access and coverage checks; no subscription or credentials are assumed. True liquidation event coverage is distinct from an OI/price/volume/funding pressure proxy.

## Shared features and TA

Each engine accepts completed bars and point-in-time auxiliary frames. Multi-timeframe joins use backward as-of on availability, not bar-open times. Fit/calibration state is saved by training fold. Every output includes its input coverage, warm-up requirement, definition and interpretation; missing source families remain null with a reason.

EMA alpha=2/(n+1); Wilder smoothing alpha=1/n. TR=max(H-L,|H-Cprev|,|L-Cprev|); ATR is Wilder(TR). DMI uses positive/negative directional moves; ADX smooths |DI+-DI-|/(DI++DI-). RSI=100-100/(1+avg_gain/avg_loss). StochRSI rescales trailing RSI extrema. MACD=EMA12-EMA26 with EMA9 signal. CCI=(typical-SMAtypical)/(.015*mean absolute deviation). WilliamsR=-100*(HH-C)/(HH-LL). TSI=100*doubleEMA(delta)/doubleEMA(|delta|). Awesome oscillator=SMA5(mid)-SMA34(mid).

Supertrend uses carried ATR bands and stateful reversals. Ichimoku spans are presented at the time they become computable; a plotting displacement is not permission to access future prices. SAR updates recursively with acceleration caps. Regression slope and R² use trailing closes. Donchian breakout references previous completed extrema. Keltner=EMAtypical +/-2ATR. Bollinger %B and width use trailing mean/std; squeeze compares width to its trailing quantile.

OBV accumulates sign(deltaC)*volume; CMF is rolling money-flow volume/rolling volume; MFI uses positive/negative typical-price flow. VWAP bands weight typical-price deviations by volume and are explicitly bar approximations unless tick second moments are present. Anchors are predeclared UTC day/session boundaries. Volume profile allocates bar volume at typical price and is labeled approximate; POC=max-volume bin, value area covers 70%. Confirmed swing pivots require right-hand bars, and the feature becomes available only on confirmation. Previous-day pivots and swing-derived Fibonacci levels use only completed history. Divergence compares confirmed extrema; weak candle-pattern features are not independently sufficient trade rules.

Confluence=sum(w_tf*trend_momentum_tf)/sum(w_tf), with nonnegative training-only reliability weights. Equal weights are an explicit untrained fallback. No holdout performance is used to determine weights.

## Quant diagnostics

RV=sum(r²), BV=(pi/2)*sum(|r_i*r_(i-1)|); positive RV-BV is a jump proxy. Formal BNS standardized test uses tripower quarticity and sampling assumptions, reported separately. Down/up semivariance split r² by sign. HAR forecasts next daily RV from 1/5/22-day RV using expanding training-only regression. GARCH h=w+a*e²+b*hprev; GJR adds g*I(e<0)*e²; EGARCH models log h. Student-t innovation fits use trailing windows, convergence diagnostics and causal forecast timestamps.

EVT fits a GPD to trailing loss exceedances above a training-defined quantile: VaR=u+beta/xi*((tail_probability/exceedance_probability)^(-xi)-1), with log limit xi->0; CVaR=(VaR+beta-xi*u)/(1-xi) requires xi<1. Unstable/insufficient tails yield null. Return quantiles, skew and excess kurtosis use trailing windows.

HMM inference uses forward-filtered probabilities, never smoothed posteriors. Regime semantic names depend on fitted emission ordering; heuristic fallback is labeled rules, not HMM. Kalman trend/state beta updates with measurements available at each step. CUSUM uses training-only location/scale and past innovations; it is not retrospective segmentation.

Cont OFI uses best bid/ask price/size changes with their correct signed indicator terms. VPIN uses fixed-volume buckets and absolute buy/sell imbalance, with warm-up and a bucket-size contract. Kyle lambda estimates trailing price changes on signed volume; Amihud=|return|/dollar_volume. Realized spread needs a future quote horizon: its availability is delayed accordingly. Impact curves fit only completed historical outcomes.

Exponential Hawkes lambda(t)=mu+alpha*sum exp(-beta*(t-ti)), branching ratio n=alpha/beta. Fit via conditional likelihood in bounded trailing event windows, constrain n<1 for stationary interpretation. Aggregated exchange trades are aggregated arrivals, not a complete point-process of individual fills. True liquidation Hawkes fits require real event data; a proxy cannot silently become observed liquidation events. A ratio near one indicates persistence under the model, not certainty of a cascade.

Funding z-score is trailing standardized funding. Perp/spot basis=(perp-spot)/spot with synchronized availability. OI drops plus price shocks, volume spikes and extreme funding form a bounded pressure proxy. OI quadrant attribution (new longs/shorts or liquidation pressure) is a heuristic and cannot uniquely identify trader actions. Leverage-tier cluster heatmaps assume tier weights and collateral; estimated liquidation levels P*(1 +/-1/leverage) with maintenance adjustment are scenarios, not exchange-account observations. Display notional as assumed allocation of reported OI, distance/ATR, and sensitivity to assumptions.

Hurst, variance ratio, lag autocorrelation, sample/permutation entropy and OU half-life are trailing diagnostics with constant-series safeguards. OU regression deltaX=a+bXprev gives half-life=-ln2/ln(1+b) only for stable mean reversion. Cointegration/Johansen/Granger/PCA/correlation and copula estimators fit rolling synchronized BTC/ETH windows; statistical diagnostics do not prove causal lead-lag. DCC parameters are fitted on training windows; an EWMA correlation fallback must be named EWMA. Wavelet and Hilbert transforms are trailing-window endpoint summaries: whole-sample centered transforms are forbidden.

Almgren-Chriss scenario cost is spread/2 + eta*participation + gamma*signed_size with coefficients fit to available execution data or marked assumptions. Vol targeting caps exposure by target_vol/forecast_vol. Fractional Kelly uses validated calibrated edge/variance and hard exposure caps. CVaR sizing caps exposure so forecast tail loss fits the risk budget. Triple barriers execute at the next observable open; stop-first ambiguity is conservative. Meta-labels are conditioned on a predeclared primary strategy; uniqueness weight is average inverse concurrent label count. Fractional differentiation truncates weights by a declared threshold and uses only trailing observations.

## Decision model and simulation

Seven causal TCN encoders (30s,1m,5m,15m,1h,4h,1d) produce embeddings from completed-bar windows. Cross-timeframe attention merges embeddings with TA/quant/flow/news/regime/position vectors and masks missing inputs. Heads: continuous target exposure, value, direction logits, ordered return quantiles, drawdown/tail-risk, and family attribution summaries. Attention is descriptive model weighting, not causal importance. Integrated gradients use fixed training-derived baselines; explanations are deterministic templates over observed structured fields. Counterfactuals are model-local sensitivity scenarios, not feasible price forecasts.

Supervised pretraining targets future return quantiles, vol and regime under purged temporal splits. IQL warm-start uses recorded transitions with next-open fills, expectile value regression and advantage-weighted behavior cloning; deterministic synthetic logs must be labeled simulator transitions, not actual trader logs. Recurrent PPO and SAC then use a realistic perpetual research simulator; QR-DQN is separately evaluated only if implemented and tested. Each trial is versioned and seeded; short smoke runs cannot validate an edge.

Simulator state includes mark price, entry price, position, leverage, cash/equity, time-in-position and risk moments. Requested exposure lies [-1,1] times leverage cap. Execution occurs after latency at next open with spread, fees, impact and slippage; funding uses observed scheduled timestamps and sign. Maintenance liquidation uses intrabar adverse high/low, conservative execution and a liquidation fee; bankruptcy truncates episodes. Costs/noise are randomized only with reproducible RNG. Reward is differential Sharpe/Sortino less turnover, drawdown and trailing CVaR penalties. Equity accounting is authoritative; reward is not P&L.

## Validation, promotion and serving

Most recent 6-12 months are untouched at the first registered run. Training folds use expanding/walk-forward and combinatorial purged CV, embargo across label horizons and contiguous windows. Every preprocessing, encoder, reliability weight, calibration and hyperparameter fit belongs inside the training fold. Repeated holdout inspection/tuning forfeits its untouched status.

Compare full pipeline and TA-only/quant-only/flow-only ablations to matched-risk buy-hold, TS momentum and calibrated GBM after costs; report actual tested coverage and failures. Metrics include Sharpe, Sortino, Calmar, DD, CVaR, turnover, bootstrap intervals and regimes. DSR/PBO need a registered set of comparable trials; insufficient trial history returns unavailable, never a made-up statistic. SOL has no March 2020 history; March-2020-style stress is synthetic and separately labeled. May 2021/FTX/Oct 2025 historical windows are stress diagnostics, not untouched evaluation if included in training.

The streaming worker builds bars and calls the same feature functions as research, records publication times, checks stale/missing feeds and measures actual latency. Sub-second latency is a target, not a claim until measured. New engines remain research-only/HOLD until validated. Existing champion/challenger policies remain in force. API endpoints expose TA/quant/coverage/explanation and interval candles; frontend adds confluence, liquidation estimates, uncertainty, quant diagnostics and ablations. Persistent probability/proxy labeling accompanies these panels.

## Delivery and evidence

Architecture → tick acquisition/bar validator → TA → volatility/regime/flow quant → perpetual simulator/baselines → pretraining/IQL/PPO/SAC → interpretation → streaming → frontend → actual validation report. Each module has future-perturbation, numerical stability and accounting checks as applicable. Missing providers, inaccessible histories, unimplemented advanced estimators and failed research gates are reported explicitly rather than hidden behind numeric defaults.
